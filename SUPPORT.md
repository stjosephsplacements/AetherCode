# Getting help

- **Questions and ideas:** start a thread in
  [Discussions](https://github.com/AlgoQX/AetherCode/discussions).
- **Bugs:** open an issue using the bug report form, including the version,
  deployment mode (single-server or Helm) and steps to reproduce.
- **Feature requests:** open an issue using the feature request form.
- **Security vulnerabilities:** never file a public issue. Follow
  [SECURITY.md](SECURITY.md) and report privately.

Before opening an issue, check the [documentation](docs/) and search existing
issues and discussions.
