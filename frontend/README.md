# Frontend

The AetherCode platform's web UI: Next.js (App Router, TypeScript), talking only
to the Go platform through the gateway. It has no database and no grading
logic of its own (ADR-0017).

It is built in Phase 3 of `docs/superpowers/plans/2026-10-02-go-platform-exam-parity.md`,
porting the screens of `apps/exam-v1`.
